设置

      

        
内容安全

        
        
开启时默认隐藏成人与受限标签、目录和例图。关闭后才显示相关内容。

      

      

        
缓存

        
        
当前设置为 1024MB。达到上限后自动清理最久未使用的网上例图；设为 0 表示不保留新缓存。

        

          网上例图0 MB
          NovelAI 标签例图0 MB
          NovelAI 图库0 MB
        

        

          
          
        

      

      

        
NovelAI 生图

        
        
        
单个批次最多可排队 6 张；请求会严格串行发送。数值越大，潜在 Anlas 消耗越高。

        
        
        
生成标签例图时使用的默认提示词。{tag} 会被替换为目标标签（自动加双花括号强调），{rating} 替换为 safe / nsfw。必须保留 {tag} 占位符。

      

      

        
百度翻译

        
        
        
凭据仅保存在本机用户设置文件；翻译文本会发送到百度翻译。只有点击翻译按钮才会请求，不会自动上传。

      

      

        
自定义标签

        
保存在本地的自定义标签（不在 Danbooru 词库中时使用）。也可在购物车点「＋ 自定义标签」直接添加并加入当前提示词。

        

      

      

        
网络与账号

        
        
        
        
        
        
Danbooru 使用用户名 + API Key；NovelAI API Key 用于官方生图接口。凭据仅保存在本机用户目录，不写入项目文件。

      

      

        

        

        
        
      

    

   


  

    

      
添加自定义标签

      
自定义标签会保存到本地词库，之后在搜索中也能直接命中（来源：自定义）。标签建议用英文（NovelAI 语法），例如 original character、my_style。
